# Cognitive Load — Quick Reference

Consult this when you notice an interface feels overwhelming, confusing, or demanding. Not every review needs this — only pull it when cognitive load is a relevant concern.

---

## The Rule

Humans hold 4 items in working memory at once. At any decision point, count what the user must simultaneously consider:

- **4 or fewer** — fine
- **5-7** — group or progressively disclose
- **8+** — they're drowning

Thresholds: nav menus 5 max, form groups 4 fields, action buttons 1 primary + 1-2 secondary, dashboard metrics 4 visible, pricing tiers 3.

---

## Three Types of Load

**Intrinsic** — the task itself. Can't eliminate, but structure it (steps, scaffolding, progressive disclosure).

**Extraneous** — bad design. Pure waste. Confusing nav, unclear labels, visual clutter, inconsistent patterns, unnecessary steps. Eliminate ruthlessly.

**Germane** — learning effort. Good load. Support it with consistent patterns and feedback.

---

## 8 Red Flags

1. **Wall of Options** — 10+ choices, no hierarchy
2. **Memory Bridge** — must remember previous screen to act on current one
3. **Hidden Navigation** — must build a mental map of where things are
4. **Jargon Barrier** — domain language forces translation
5. **Visual Noise Floor** — every element same visual weight
6. **Inconsistent Patterns** — same actions work differently in different places
7. **Multi-Task Demand** — reading + deciding + navigating simultaneously
8. **Context Switch** — jumping between screens for info needed in one decision
