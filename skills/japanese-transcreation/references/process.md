# Detailed Transcreation Workflow

Step-by-step workflow with examples. Read SKILL.md first for the core process.

---

## Step 1: Understand — Worked Example

**Source page:** A workshop pitch page for a tech company.

**Page purpose:** Convince the client this AI workshop is worth investing in. Everything serves persuasion.

**Block function breakdown:**

| Block | Function | Implication |
|-------|----------|-------------|
| Hero tagline | Evoking | Aspirational, confident. Can use plain form. |
| Bridge paragraph | Scene-setting | Creates urgency. Presents and describes — no commands (no ください). |
| Framing line | Presenting | Structural. Sets up the arc. Confident. |
| Session descriptions | Presenting | Informational but still selling. Forward-moving energy. |
| Deliverables | Presenting | Value props. Concrete, specific. |
| CTA | Inviting | Soft invitation. This is where ください-adjacent forms are OK. |
| Portal onboarding | Instructing | The reader has opted in. ください is appropriate here. |

The key insight: the same word (ください) can be right or wrong depending on block function. A pitch paragraph presents. A CTA invites. A form instructs. Each needs different language.

---

## Step 2: Abstract — Worked Example

**English source (lyrical copywriting style):**

> Most people have tried AI. Some gave up. Some ask it simple things. The speed of technology is only moving faster. Becoming more powerful, more intelligent. This workshop is so you can catch up, and get ahead.

This is 6 fragments with intentional rhythm. The lyrical style is *maximally hostile* to literal Japanese translation — every fragment and parallel structure is exactly what Japanese can't do the same way.

**Abstract:**

> Many people have tried AI but most aren't using it well — gave up or only use it for simple questions. Technology keeps accelerating. This workshop exists to help you catch up with that pace and get ahead of it.

The English fragments are gone. The meaning is preserved. The Japanese will be written from this, not from the fragments.

## Step 3: Generate — Key Patterns

### Clause chaining reference

| Form | Function | Example |
|------|----------|---------|
| 〜て / 〜で | Sequential/causal | 食べて、寝た |
| 〜し | Listing reasons | 安いし、おいしいし |
| 〜ので / 〜から | Causal | 雨なので中止した |
| 〜ため | Purpose/cause (formal) | 確認のため |
| 〜けど / 〜が | Contrastive | 高いけど買った |
| 〜ながら | Simultaneous | 歩きながら考えた |
| 〜たり | Non-exhaustive listing | 食べたり飲んだりした |

### Sentence merging guide

| English pattern | Japanese approach |
|----------------|-------------------|
| 1 short sentence | Often becomes part of a larger Japanese sentence |
| 2-3 related sentences | Merge into 1 Japanese sentence with clause connectors |
| 4+ sentences (a paragraph) | 2-3 Japanese sentences with natural flow |

### Cultural adaptation patterns

These aren't rules to check against — they're natural consequences of writing from intent for a Japanese audience:

| English pattern | What happens naturally in Japanese |
|----------------|-----------------------------------|
| Bold claims about the reader's business | General observations or contextual framing |
| Rhetorical questions as CTAs | Soft invitations (まずは〜, 〜してみませんか) |
| Superlatives (best in class) | Specific facts and numbers |
| Direct commands (buy now) | Gentle suggestions (ぜひご検討ください) |
| FOMO (don't miss out) | Trust-building (多くの企業様にご活用いただいています) |
| Abstract nouns (productivity, connectivity) | Verbal constructions (生産的に働く, つながる) |

## Step 4: Verify — What to Scan For

Read the output as a whole, as a native reader would. These are mechanical issues that can survive even a good process:

**Fragment rhythm.** Count sentence-ending periods. If a Japanese paragraph has more periods than the English source had paragraphs, merge sentences with clause connectors.

**Em dashes.** Japanese doesn't use —. Replace with 。, 、, or restructure to integrate the aside naturally.

**Register breaks.** If a section starts with です/ます, every sentence should end that way. Mixing plain and polite form within a section is jarring.

**Pronoun buildup.** If you see あなた or 私たち more than once in a paragraph, rewrite. Drop them — let the topic carry.

**Insider terms.** Read each technical term and ask: would someone unfamiliar with the product understand this word? If not, consider rewriting or briefly clarifying.

## Handling Lyrical / Rhythmic English Source

When the English source uses intentional fragments, parallel structures, or spoken-word cadence (common in creative copywriting), the abstraction step is especially critical. This style is maximally hostile to literal Japanese translation.

Do not try to preserve the rhythm. Find the Japanese way to create the same emotional momentum:
- Clause chaining builds momentum through connected flow
- Writing-system mixing (kanji density vs hiragana softness) creates texture
- Concrete specificity creates impact where English uses punchy abstraction

The source text's rhythm served a purpose in English. Identify that purpose and achieve it with Japanese tools.
