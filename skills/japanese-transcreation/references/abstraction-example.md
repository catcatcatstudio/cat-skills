# Abstraction Example

The abstraction step exists to break free from English sentence structure. Here's the difference between abstracting too literally and abstracting to the actual job.

**English source:**
"Most people have tried AI. Some gave up. Some ask it simple things. The speed of technology is only moving faster. Becoming more powerful, more intelligent. This workshop is so you can catch up, and get ahead."

**Too literal (bad):**
"Many people have tried AI but aren't using it well. Technology keeps accelerating. This workshop helps you keep up and get ahead."

This is just simpler English. The sentence structure still leaks through — a translator given this would produce the same anchored output.

**Real abstraction (good):**
"Job: create urgency. Reader should feel behind but not hopeless. Key facts: most AI usage is shallow, tech is accelerating, workshop closes the gap."

This describes the *job* and *key facts*. A Japanese copywriter given this brief would write completely different sentences than a translator given the English. That's the point.
